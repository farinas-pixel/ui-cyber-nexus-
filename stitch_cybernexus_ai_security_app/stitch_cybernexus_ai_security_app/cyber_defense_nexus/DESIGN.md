## Brand & Style

The design system projects absolute authority, defensive precision, and hyper-advanced artificial intelligence. Tailored specifically for Android-first elite SecOps operators, incident responders, and cyber intelligence analysts, the interface establishes an atmosphere of calm composure amidst high-frequency operational crises. The emotional response is centered on total system legibility, uncompromised structural integrity, and futuristic precision.

The visual expression fuses futuristic 3D Glassmorphism with technical telemetry instrumentation. Deep spatial recession (#050B16 into #0A1528) establishes an infinite void backdrop, layered with translucent acrylic shells that catch refracted ambient light. Holographic structural borders, directional edge glows, and micro-grid sub-surfaces simulate a secure tactical display environment without sacrificing fluid Android touch interactions.

## Colors

The palette is engineered exclusively for an OLED dark environment with luminous visual feedback states:

- **Base Void (`#050B16`):** Canvas backdrop, absorbing ambient reflections to maximize panel contrast.
- **Sub-Surface Canvas (`#0A1528`):** Recessed telemetry wells, structural rails, and under-glass groupings.
- **Glass Core (`rgba(10, 21, 40, 0.65)`):** Dynamic front-facing glass plate with embedded specular border `rgba(33, 212, 253, 0.25)`.
- **Primary Core (`#147DCC`):** The structural defensive anchor; used for active threat mitigation vectors, primary touch targets, and critical perimeter lines.
- **Electric Cyan (`#21D4FD`):** High-frequency signals, packet bursts, live network tracer lines, and real-time biometric confirmations.
- **AI Violet (`#8B5CF6`):** Autonomous neural engine activity, behavioral anomaly detections, and predictive heuristics.
- **Text Primary (`#F1F7FF`):** Zero-chroma white with an icy tint to eliminate contrast bloom while maintaining crisp readability.
- **Text Muted (`rgba(241, 247, 255, 0.60)`): Secondary metric labels, telemetry descriptors, and system timestamps.

## Typography

The typographic hierarchy utilizes three specialized typefaces:
- **Headlines (`Space Grotesk`):** Structural, geometric, and technical without feeling retro. High tabular stability makes it suited for threat counters, system nodes, and interface anchors.
- **Body (`Geist`):** Delivers clean readability on high-density mobile displays, remaining legible against translucent layered backdrops.
- **Labels & Telemetry (`Space Mono`):** Dedicated to node IDs, timestamps, protocol signatures, hex dumps, and runtime indicators. Rendered in uppercase by default to preserve tactical rhythm.

## Layout & Spacing

The layout model runs on a strict 8pt grid with 4pt baseline snap points for dense telemetry widgets.
- **Grid Architecture:** 4-column layout on standard portrait mobile devices with 12px gutters, expanding to an 8-column layout on foldable unfolding states or landscape tablets with 16px gutters.
- **Tactile Margins:** 16px lateral padding guarantees clearance from native Android edge-to-edge gestures and display curvature.
- **Reflow & Docking:** Critical response controls sit within a fixed thumb-zone docking glass rail across the lower 96dp of the screen, floating with safe-area bottom elevation.

## Elevation & Depth

Visual hierarchy uses physical-refraction glassmorphism, directional backlights, and volumetric glows:

- **Level 0 (Surface Base):** Pure `#050B16` with a micro-grid layer (`rgba(33, 212, 253, 0.03)` 16px mesh).
- **Level 1 (Sub-Panels & Trays):** Semi-opaque `#0A1528` with flat 1px outlines (`rgba(255, 255, 255, 0.05)`).
- **Level 2 (Tactical Glass Cards):** `rgba(10, 21, 40, 0.65)` layered over `backdrop-filter: blur(24px) saturate(180%)`. Border: 1px continuous solid `rgba(33, 212, 253, 0.25)`. Inner edge highlight: top edge inset shadow `inset 0 1px 1px 0 rgba(241, 247, 255, 0.2)`. Drop shadow: `0 16px 32px -8px rgba(0, 0, 0, 0.7)`.
- **Level 3 (Interactive Floating Nodes):** Active glass state with border glow `0 0 12px rgba(33, 212, 253, 0.45)`, drop shadow `0 20px 40px -4px rgba(5, 11, 22, 0.9)`, and bottom refraction gradient overlay.
- **Level 4 (Modal & Critical Overlays):** Full-bleed dynamic glass veil with secondary internal focal glow generated by an AI Violet radial gradient (`rgba(139, 92, 246, 0.15)`).

## Shapes

The design uses balanced rounded geometry (`roundedness: 2`, 8px base radius). This produces clean structural containers across high-density telemetry panels while softening mobile touch footprints:
- Standard interactive elements, metrics containers, and cards use 8px (`rounded-md`).
- Primary modal containers and master containment cards use 16px (`rounded-lg`).
- Telemetry badges, status indicators, and micro-switches use 24px (`rounded-xl`) or fully circular pills for scan indicators and pulse nodes.

## Components

### Buttons & Interactive Triggers
- **Primary Cyber Action:** Filled `#147DCC` backed by an Electric Cyan rim light. Text set in `label-lg` with `Space Mono`. On tap, trigger an internal sweep shine animation from left to right.
- **Secondary Glass Trigger:** `rgba(10, 21, 40, 0.65)` fill with 1px `rgba(33, 212, 253, 0.35)` border and electric cyan text. Under hover/press, border alpha increases to 1.0 with a `0 0 8px rgba(33, 212, 253, 0.5)` drop glow.
- **Hazard Containment Button:** Desaturated AI Violet outline transitioning to intense crimson warning pulse during destructive override operations.

### Holographic Cards
- Double-layered glass: A recessed canvas backplate beneath an elevated frosted surface.
- Corner accents: 1px micro-brackets on top-left and bottom-right corners using Electric Cyan.
- Interior layout incorporates dynamic visual telemetry lines separating metadata headers from actionable metrics.

### Chips & Telemetry Badges
- Built with pill-shaped boundaries (`rounded-xl`).
- Background: `rgba(20, 125, 204, 0.15)`. Border: 1px `rgba(33, 212, 253, 0.4)`. Text: `label-sm` with `Space Mono`.
- Active State: Embeds an animated 6px pulse dot with an expanding outer echo ring indicating live sensor heartbeats.

### Input Fields
- Terminal-inspired text entries: Background `rgba(5, 11, 22, 0.7)` recessed within 1px `rgba(33, 212, 253, 0.2)` borders.
- Focused State: Border converts to pure `#21D4FD` with an inner shadow blur of 8px, paired with a blinking monospace block cursor.
- Field labels float as uppercase `label-sm` tags directly on the top border rail.

### Selection Controls (Checkboxes & Radios)
- Checkboxes: 18x18px chamfered or rounded squares (4px radius). When checked, fills with Electric Cyan `#21D4FD` featuring an inverted `#050B16` angled checkmark.
- Radio Nodes: Concentric dual-ring circles with a pulsating AI Violet core dot when armed.

### Lists & Activity Feeds
- Log entries use transparent striping separated by 1px horizontal gradient lines that fade to `transparent` at both canvas margins.
- Left edge incorporates an active threat status color stripe (Primary Blue for normal traffic, Electric Cyan for dynamic inspection, and AI Violet for autonomous quarantine).
